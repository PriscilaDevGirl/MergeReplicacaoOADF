# Fontes e materiais de terceiros

- **Estudo de referência:** Moraes, Borba e Da Silva, *Semantic conflict detection via dynamic analysis*, SBLP 2024. DOI: https://doi.org/10.5753/sblp.2024.3471. O PDF fornecido para leitura não é redistribuído neste repositório.
- **Underscore:** https://github.com/jashkenas/underscore. Os arquivos históricos e trechos anotados/exportados preservam seus comentários de autoria. A licença MIT está incluída em `licenses/underscore-LICENSE.txt`; ela se aplica às cópias e trechos substanciais desse projeto.
- **MiningFramework:** https://github.com/spgroup/miningframework, commit `7a9503f0e3af110fb0028fb02753d4c4a627266e`. Os clones locais não são incluídos. O patch de build registra duas adaptações de compatibilidade, sem alteração no algoritmo do coletor.
- **Jalangi2:** https://github.com/Samsung/jalangi2, commit `bc879287b1678de6e3c423f5debe63207559525b`. O clone não é incluído. É necessário instalar essa ferramenta e suas dependências para executar o analisador independente.
- **MergeDataSet:** https://github.com/spgroup/mergedataset. O catálogo de origem está identificado pelo blob `e617e0955c12c1563f0112c0bcd750aeeb86e089`; o inventário preserva os rótulos publicados e não representa nova validação dos conflitos.
- **jsFSTMerge:** https://github.com/AlbertoTrindade/jsFSTMerge. O relatório e as tabelas registram a mineração exploratória; as quádruplas Java exportadas para inspeção local não fazem parte do pacote versionado.

O analisador `analisador_oa/analysis.js` é uma reimplementação independente experimental. Ele não deve ser atribuído à Amanda nem apresentado como seu código original. Este documento não altera as licenças dos materiais de terceiros.
